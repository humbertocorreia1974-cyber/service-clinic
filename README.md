# service-clinic
Site institucional que gera lead + plataforma completa de field service para a Service Clinic: manutenção preventiva e corretiva de equipamentos odontológicos, higienização técnica de ar-condicionado em ambiente clínico (biossegurança/PMOC) e revenda de peças, cobrindo Volta Redonda, Pinheiral, Barra Mansa, Resende e Barra do Piraí.
